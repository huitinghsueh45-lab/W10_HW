段落一：為什麼要學生成式 AI 原理？（Why）

生成式 AI 入門：從函數 fθ 到 Transformer

教 AI 用你的方法做事，用底層原理（含數學直覺）徹底消除三大 AI 焦慮

😰 焦慮 1：我會被 AI 取代嗎？

常聽到「會取代你的是會用 AI 的人」，擔心 AI 比自己更厲害。

原理破局：現代 AI 其實只是沒有意識、不會自己分析的「呆萌型 AI 機器人」，必須由領域專家定義輸入與輸出。

🌪️ 焦慮 2：每天都有新工具學不完？

ChatGPT、Claude、Gemini、Grok、Llama 每天推陳出新，不知哪個最好。

原理破局：所有大型語言模型的基礎模型原理幾乎相同，懂一個就懂全部，成為強大的吸收器。

🧩 焦慮 3：技術名詞看起來好難？

Prompt / Context / Harness / Loop / Graph Engineering、Chat Bot、AI Agent 令人眼花撩亂。

原理破局：這些名詞本質上都只是「教 AI 做事的方法」，看懂函數與機率就不再被術語嚇倒。

🎯 掌握原理帶給你的四個超能力

  • 看清限制並突破：知道 AI 為什麼會出錯，才能設計流程突破限制。
  • 不盲目追逐模型：明白如何挑選與測試適合自己任務的模型。
  • 懂得為何引導有效：理解為什麼提供「正確的資訊＋清楚的指引」能改變條件機率。
  • 本簡報學習主線：函數映射 fθ → 神經網路與梯度下降 → 資訊熵與隨機抽樣 → Transformer。

段落一：為什麼（Why — 生成動機與核心矛盾）

為什麼要讓電腦「創作」？為什麼不能直接一對多訓練？

從圖靈與費曼的提問，看見生成式 AI 最關鍵的「一對多平均困境」

💡 人類探索生成模型（Generative Models）的三大動機

  1. 讓電腦具備創作力：不只做分類判斷，更能生成全新的圖像與文字作品。
  2. 圖靈的問題（Alan Turing, 1950）：在還沒有現代電腦的 1950 年，圖靈便提問：「透過無線打字機對話，人類能否分辨對方是真人還是機器？」
  3. 費曼的創造哲學（Richard Feynman）：
    "What I cannot create, I do not understand."
    （我無法創造的事物，就代表我還沒有真正理解。）

⚠️ 創作型 AI 的第一道牆：「一對多」不是函數！

如果我們直接把提示詞 "一個可愛的女孩" 當作輸入，但訓練資料中有 N 張長相不同的可愛女孩照片：

同樣輸入 x 對應多個不同輸出 → 硬訓練會得到 算術平均： 圖1 + 圖2 + ⋯ + 圖NN
  • 災難後果：所有照片疊加平均後變成模糊的「四不像」，失去創作意義！
  • 解決方向：(1) 在輸入端加入隨機抽取的潛張量（Latent Tensor, z）代表天馬行空的想法；或 (2) 讓模型輸出機率分佈再進行隨機抽樣！

段落二：是什麼（What — 核心概念 1：函數映射與張量）

AI 模型是什麼？從張量輸入到機率輸出的「函數學習機 fθ」

不論判別式或生成式 AI，底層都是接收數字張量、輸出數字張量的函數

📐 輸入與輸出都必須是「張量（Tensor）」

電腦不懂人類語意，所有輸入 xi 與輸出 ŷi 都是由數字組成的張量：

張量階數數學名稱實例（來自 Wiki 記載）
0 階 Tensor純量（Scalar）單一數字 x = 9487
1 階 Tensor向量（Vector）一串數字 x = [9, 4, 8, 7]、784 維拉平影像
2 階 Tensor矩陣（Matrix）某股過去 20 天 × N 個特徵（開盤、最低、收盤）
3 階 Tensor3D 矩陣彩色照片的 R、G、B 三個通道像素陣列
輸入 xi ──( fθ )──▶ fθ(xi) = ŷi = y1y2y3

🐦 以「台灣八哥辨識」看懂 Softmax 機率轉換

表面上模型回答「土八哥」，實際上 fθ 輸出三個分數 (a, b, c)，再經 Softmax 先取指數轉為正數、後除以總和 S = ea + eb + ec 化為條件機率 Pθ(yi | x) = pi：

Softmax(a, b, c) = ( eaS, ebS, ecS ), ∑ pi = 1

段落二：是什麼（What — 核心概念 2：神經網路架構）

神經網路是什麼？基本運算單元「神經元」與 3+1 種主流架構

由神經元組裝出近乎全能的函數學習機（Universal Approximation Theorem）

⚡ 基本運算單元：單一神經元（Neuron）三步驟

不論哪種深度學習模型，每個神經元的運算方式都完全一樣：

  1. 加權總和：輸入刺激 x1, x2, x3 乘上權重 w1, w2, w3 得總刺激 w1x1 + w2x2 + w3x3。
  2. 加上偏值（Bias, b）：做基準調整，得 ∑ wixi + b。
  3. 非線性激發函數（Activation Function, φ）：純線性算式疊再多層仍是線性的，必須經激發函數（如本世紀新寵 ReLU，或舊時代的 Sigmoid）轉換後送出：
h = φ( w1x1 + w2x2 + w3x3 + b )，學習參數 θ = {w1, w2, w3, b}

📌 萬用近似定理（Universal Approximation Theorem）：數學證明只要「一個隱藏層」的神經網路，理論上就能學會你要學的函數！

🏗️ 深度學習的「3 + 1」種神經網路架構

隱藏層神經元的不同連結方式，構成了現代 AI 的四大支柱：

架構名稱核心隱藏層專長與結構特性
1. DNN全連結層 (Dense)前一層連到下一層每個神經元；全面考慮的基本型（只需決定幾層、每層幾個神經元）
2. CNN卷積層 (Conv)圖形與影像辨識天王
3. RNN遞歸層 (LSTM/GRU)有記憶的結構，把上次輸出 ht-1 傳回與本次 xt 結合
+1. TransformersSelf-Attention現代大型語言模型與多模態生成的核心架構

💡 為什麼上世紀神經網路沒成功？三巨頭（Hinton、LeCun、Bengio）指出當年欠缺三大要件：複雜的軟體、大量的數據、電腦計算能力。

段落二：是什麼（What — 核心概念 3：LLM 與詞嵌入）

大型語言模型（LLM）是什麼？「猜下一個字」與詞嵌入表徵

把全世界所有句子變成訓練資料，並用隱藏層學出帶有「語意」的特徵代表向量

🗣️ 為什麼「只看前一個字」不是函數？

LLM 的核心任務是「看前面一堆字，預測下一個字」（自監督學習：如 "炎龍老師很帥" 可自動拆出 (炎)→龍、(龍)→老 等無限訓練對）。

但若只輸入「前一個字」訓練 "今天天氣很好。"：

fθ("天") = "天" 　且　 fθ("天") = "氣" 　（一對多，違反函數定義！）

👉 結論：語言模型必須是「有記憶的」神經網路，將前面所有字 x1, …, xt-1 融合為記憶向量 ht-1，計算條件機率 Pθ(wi | x1, …, xT)！

🧭 Word Embedding：讓數字向量帶有「文字的意思」

  • One-hot 的缺陷：把 的=1, 一=2, 我=5 轉成只有一個 1 的向量，本質還是流水編號，毫無語意距離。
  • 代理任務（Pretext Task）：設計「電腦必須懂輸入才能完成」的小任務，取中間隱藏層輸出（如 128 維）作為特徵代表向量（Embedding）。
  • Word2Vec（Mikolov et al., 2013）兩種代理任務：
    • CBOW：用周圍字 (xt-2, xt-1, xt+1, xt+2) 預測中間字 xt。
    • Skip-Gram：用中間字 xt 預測周圍的字。
  • 權重即記憶：One-hot 乘上權重矩陣 WTx = h 就是直接抽出對應列向量（Transformer 則內建 Embedding 層同步訓練），相似字自動群聚且滿足「國王 − 男人 + 女人 = 皇后」！

段落三：怎麼運作（How It Works — 機制 1：損失函數與梯度下降）

機器怎麼學會函數？從資訊熵、交叉熵到梯度下降法

用 Cross Entropy 評估機率分佈差距，再用微積分切線斜率自動找到最佳參數 θ*

📉 為什麼分類與語言模型偏愛 Cross Entropy 而非 MSE？

  • 資訊量（驚訝指數）：I(x) = −log P(x)（機率越低越驚訝，如加州明天下大雨）。
  • 夏農熵（Entropy）：平均訊息量（亂度）H(P) = −∑ pi log pi。
  • 交叉熵（Cross Entropy）：比較真實分佈 P(y) 與預測分佈 Q(ŷ)：
H(P, Q) = −∑ yi log ŷi = −log ŷi （當第 i 類為正確答案 yi = 1）
正確答案 y = [1, 0, 0]MSE 均方差Cross Entropy物理意義
預測 A：[0.7, 0.19, 0.11]0.140.36正確類別皆為 70%，Cross Entropy 視為一樣好；若正確類機率極低則給予大扣分！
預測 B：[0.7, 0.30, 0.00]0.180.36

註：若在模型蒸餾學習老師模型的 Soft Target（如 [0.7, 0.2, 0.1]），則使用 KL 散度 DKL(P∥Q) = H(P,Q) − H(P)（差距可放大 3 倍：0.01 vs. 0.03）。

⛰️ 梯度下降法（Gradient Descent）：萬用參數學習律

目標是調整參數 θ 讓損失 L(θ1) > L(θ2) > … 走到最小值 L(θ*)：

  1. 單一參數看切線斜率：微積分切線斜率 L'(w) = dL/dw 指向局部極大值方向，因此往極小值必須減去斜率。
  2. 乘上學習率（Learning Rate, η）：避免一步跨太大「跑過頭」：w ← w − η (dL/dw)。
  3. 多參數偏微分與梯度向量 ∇L：對每個參數「假裝只有它一個變數、其餘代入常數」求偏微分（如 L=(b1+2w1−w2−3)2 在 (1,−1,2) 化為 4w12）：
θ ← θ − η ∇L ，其中 ∇L = ∂L / ∂w1∂L / ∂w2∂L / ∂b1 （結合反向傳播 Backpropagation）

段落三：怎麼運作（How It Works — 機制 2：生成隨機性與選字旋鈕）

為什麼 AI 每次回答都不一樣？機率抽樣與 Temperature / Top-p

從 GAN 的潛變數對抗，到語言模型 Softmax 輸出端的三大選字控制旋鈕

🎲 隨機性的兩大來源與 Top-k / Top-p 截斷

  • 途徑 1（輸入端隨機）：GAN 與 StyleGAN
    生成器 G(z) 接收隨機潛向量 z 與鑑別器 D(x) 對抗（minG maxD V(D,G)）；StyleGAN 將 512 維 z 轉為風格向量 w 並以 AdaIN 注入各層。
  • 途徑 2（輸出端抽樣）：依 Softmax 機率抽字
    八哥辨識永遠挑最高分（argmax），但咖啡推薦或 LLM 猜下一個字則依機率分佈隨機抽樣（如「呆一布在」後接：家 15%、玩 12%、桌 7%、裝 3%）。
  • Top-k（如 k=50）：只留前 k 名，但遇唯一正解（「老師是蔡炎＿」必接「龍」）時仍可能混入無關字。
  • Top-p（Nucleus Sampling, ICLR 2020）：由最高分往下累加至 ∑i=1N pi > p（如 p=0.9）動態決定前 N 個字，再重分配機率 p'k = pk / P。

段落三：怎麼運作（How It Works — 機制 3：Transformer 自注意力）

Transformer 核心引擎：Q, K, V 與 Scaled Dot-Product Attention

徹底捨棄 RNN 遞迴，用列向量矩陣乘法實現 O(1) 平行生成與長距離關聯

⚡ Self-Attention 四步驟與公式（Vaswani et al., 2017）

相較於 RNN 必須 O(n) 逐步遞迴，Transformer 的循序操作數與最大路徑長度皆為 O(1)（一次平行生成）：

  1. 生成 Q, K, V（列向量右乘）：Google 偏愛列向量，故權重矩陣乘在右方：Q = XWQ, K = XWK, V = XWV。
  2. 內積算相關強度：大家輪流當 qi，計算內積 ej = qi kjT（矩陣乘法 QKT）。
  3. 除以 √dk 並做 Softmax：化為總和為 1 的注意力權重 α1, …, αT。
  4. Value 列向量線性組合：輸出融合上下文記憶的向量 hi = ∑ αj vj。
Attention(Q, K, V) = softmax ( QKTdk ) V

🔍 跨來源查核：為什麼一定要除以 √dk？

• 原論文理論（Footnote 4）：若 q, k 分量平均 0、變異數 1，內積變異數會膨脹為 dk，大數值會把 Softmax 推入梯度極小區；除以 √dk 能把變異數壓回 1。
• 第五講直覺（p.32-33）：抑制 Softmax「贏者通吃」，如同設溫度 τ = √dk 把數字拉回 0 附近！

段落三：怎麼運作（How It Works — 機制 4：完整 Transformer 穩定架構）

讓 Transformer 完整且穩定：位置編碼時鐘、多頭遮罩與殘差正規化

補齊平行運算缺少的順序感、防止偷看未來答案，並讓深層網路平順收斂

🕰️ 1. 位置編碼（Positional Encoding）

平行 Self-Attention 本身不分先後順序，需在詞向量加上位置向量 xt + pt：

ωk = 1 / 100002k/d
p2k = sin(ωkt), p2k+1 = cos(ωkt)
  • 單位圓時鐘直覺：每組 (sin, cos) 就像單位圓上的順時鐘指針（低位元快、高位元慢，且數值介於 [−1, 1] 不蓋過原詞向量）。
  • 相對位置線性性質：PEpos+k 可表為 PEpos 的線性函數，易於學習相對位置與外插。

🎭 2. Multi-Head 與三種 Attention

原版 Base 模型設 N=6 層、dmodel=512、h=8 個注意力頭（每頭 dk=dv=64），平行計算後 Concat 乘上 WO：

  • Encoder Self-Attention：Q, K, V 全由輸入向量自家生產，雙向理解上下文。
  • Decoder Masked Self-Attention：將未來位置設為 −∞（Mask 遮住），保持自回歸不偷看答案。
  • Decoder 中間層（非 Self-Attention）：Q 來自 Decoder 前一層，K, V 來自 Encoder 輸出（文字生圖亦藉此混入文字特徵）。

🛡️ 3. ResNet 殘差連結與正規化演進

每個子層輸出皆為 LayerNorm(x + Sublayer(x))：

z + ℓ(z) ≃ f(z) ⟹ ℓ(z) = f(z) − z
  • ResNet 殘差連結：網路只需學習「之前還沒學到的殘差」，使損失函數地形（Loss Landscape）極度平順。
  • 正規化演進：
    • 原版：LayerNorm (x−μ)/√(σ²+ε)·γ+β
    • Llama 等：RMSNorm（省去減平均值 μ）
    • Meta 最新：DyT γ·tanh(αx)+β

段落四：例子（Examples — 從影像分類到大型語言模型）

具體數值與實作案例：看同一個函數原理如何貫穿所有 AI

從 3 維八哥分類、10 維 MNIST 手寫辨識，到上萬維字庫的 LLM 接話生成

🐦 案例 1：台灣八哥三分類

  • 輸入：1 張野外八哥彩色照片（3 階張量）。
  • 正解編碼：土八哥 One-hot 為 [1, 0, 0]。
  • 訓練前亂猜誤差：若模型輸出 [0.23, 0.43, 0.34]，單筆平方誤差和為：
    (1−0.23)² + (0−0.43)² + (0−0.34)² = 0.89。
  • 訓練後推論：輸出分數 (1.9, 1.1, 0.2) 經 Softmax 得 (61%, 28%, 11%)，取最高分判定為土八哥。

✍️ 案例 2：MNIST 手寫數字 DNN

  • 資料集：NIST 修改版手寫數字集（0～9）。
  • 輸入拉平：28 × 28 灰階影像拉平並正規化為 784 維向量。
  • 網路結構（Keras Sequential）：
    • 隱藏層 1：100 個神經元（ReLU）
    • 隱藏層 2：100 個神經元（ReLU）
    • 輸出層：10 維 Softmax（對應 10 維 One-hot）
  • 訓練：設定 Loss、以 SGD（梯度下降）設定 learning rate、batch_size 與 epochs 訓練完成。

📚 案例 3：LLM 字元接龍與規模奇蹟

  • 單步評分實例：輸入 "炎龍老師很"，對字庫編號（帥=87, 幽=94, 有=112, 熱=174, 受=221）打分 [1.40, 0.03, 1.71, -0.73, 0.95] → Softmax 得 [30%, 7%, 40%, 4%, 19%] 抽樣接龍。
  • 規模演進：課堂《紅樓夢》生成器（300 萬參數，能把孫悟空寫進賈府）→ GPT-2（15 億）→ GPT-3（1,750 億參數，讀 4,990 億字）。
  • 閱讀量對比：人類一生閱讀約 1B（10 億字），而 Llama 3 訓練資料達 15T（人類一生的 1.5 萬倍）！

段落五：常見誤解（Common Misconceptions）

初學者最容易搞混的五大迷思 vs. 原理真相

破除「背資料學 AI」的似是而非說法，建立精確的數學與工程直覺

❌ 初學者常見誤解 ✅ 底層原理真相（依據 Wiki 知識庫）
誤解 1：「鑑別式 AI 與生成式 AI 原理完全不同；因為生成式 AI 有幻覺，有時要改用鑑別式 AI。」 兩者在底層原理上完全一樣！都是神經網路 fθ 經 Softmax 輸出條件機率分佈，差別只在於最後是「固定挑最高分（argmax）」還是「依機率抽樣生成下一個字」。
誤解 2：「幻覺（Hallucination）是 LLM 程式設計失敗的錯誤（Bug）。」 Karpathy (2015) 指出 LLM 本質上是「作夢的機器」——搜尋引擎是 0% 的夢境但不會創造；幻覺正是 LLM 所做的全部，是它最具創造力的特點（只是當助理用時我們不希望它作夢）。
誤解 3：「把 Temperature 調高（τ > 1）能讓模型考慮更周全、算得更準。」 調高 τ > 1 只是把指数 ea/τ 的分數差距拉近，讓低分候選字更容易被抽中（更隨機）；若希望答案穩定一致，反而應調低 τ < 1。
誤解 4：「Transformer 裡每一層的 Attention 都是 Self-Attention（自注意力）。」 在標準 Encoder-Decoder 架構中，Decoder 中間那層不是 Self-Attention！它的 Q 來自 Decoder 前一層，但 K, V 來自 Encoder 輸出（跨模態文字生圖亦同）。
誤解 5：「深度學習就只是把沒學過的點補起來的高維度內插法（Interpolation）。」 Balestriero, Pesenti, & LeCun (2021) 證明：在高維度空間中的機器學習，幾何本質上總是外插（Extrapolation）！

🔑 原理如何指導實務？寫好 Prompt 的兩大重點

既然 LLM 是根據前面字預測下一個字機率 Pθ(wi | x1, …, xT) 的接話機器，它並不知道你腦中的背景。因此寫好 Prompt（與 Context Engineering）只有兩個重點：

  1. 正確的資訊：把專屬背景資料、限制條件講清楚（錨定正確的上下文機率空間）。
  2. 清楚的指引：要把任務目標、輸出格式、目標受眾講明白。

🤝 Prompt 必殺技：和 AI 一起寫規格書！

  1. 先給陽春方向並補充只有你知道的專屬背景內容。
  2. 請 AI 訪問你：問還有哪些需要釐清的地方。
  3. 請 AI 根據討論整理成結構化草稿／規格書（先不要直接寫成品）。
  4. 人工親自閱讀並修改：只要是 AI 生成的，務必自己讀過把關！

Q1. 若直接拿同一個提示詞「一個可愛的女孩」對應 100 張不同女孩照片硬訓練一般函數 f_θ，會發生什麼事？
✅ 正解 B：一對多不是函數！硬訓練會得到所有可能輸出的算術平均（四不像），因此需引入潛張量 z 或機率分佈抽樣。
[來源 Wiki：concepts/probability-entropy-and-sampling.md]
Q2. 在分類問題（正解 y=[1,0,0]）中，兩次預測 [0.7, 0.19, 0.11] 與 [0.7, 0.3, 0] 的 Cross Entropy 關係為何？
✅ 正解 A：One-hot 下 Cross Entropy 簡化為 −log ŷi，兩者對第一類皆預測 0.7 故同為 0.36（0.14 vs. 0.18 是 MSE 的結果）。
[來源 Wiki：concepts/probability-entropy-and-sampling.md]
Q3. 當我們希望 LLM 每次生成的文字更固定、更一致（減少胡言亂語）時，應如何調整 Temperature τ？
✅ 正解 B：在 ea/τ 中，τ < 1 會進一步拉開分數差距（例如 [4.3, 3.4, 0.2] 在 τ=0.5 時第一名機率從 70% 升至 86%），使輸出更固定。
[來源 Wiki：concepts/word-embedding-and-sampling-strategies.md]
Q4. Transformer 的 Scaled Dot-Product Attention 為什麼要將內積 QK^T 除以 √d_k？
✅ 正解 A：Vaswani et al. (2017) 證明內積變異數為 dk，數值過大會推入 Softmax 極小梯度區（贏者通吃），除以 √dk 將變異數壓回 1。
[來源 Wiki：concepts/transformer-and-self-attention.md]
Q5. 關於標準 Transformer 的 Encoder 與 Decoder 注意力層，下列敘述何者正確？
✅ 正解 B：Decoder 第一層使用 Masked Self-Attention（設為 −∞ 防止偷看未來字），而 Decoder 中間層是檢索 Encoder 先備知識 K, V 的 Cross-Attention，並非 Self-Attention！
[來源 Wiki：concepts/transformer-architecture-and-stability.md]
